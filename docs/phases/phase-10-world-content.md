# Phase 10: World Content

**Goal:** all of Kanto playable from start to end.

## Scope

- NPCs, dialogue and story events for all of Kanto, on the event system from [Phase 5](phase-5-pallet-town.md).
- Items and bag, Pokémon Centers, PokéMarts, money.
- Gyms, badges, Elite Four and Champion.
- Field moves needed to progress (e.g. Cut, Surf, Strength).
- All Kanto maps, trainers and encounters.
- Public art for all of Kanto, as done for Pallet Town in [Phase 6](phase-6-pallet-town-art.md).

## Done When

- A player can play all of Kanto from the first town to the Champion.
