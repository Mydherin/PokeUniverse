# Phase 13: Polish and Launch

**Goal:** a stable, public MVP.

## Scope

- Performance and mobile tuning.
- Pokédex extras: species forms (Unown, Deoxys, Castform, Spinda, Gen 4 forms), FireRed's L/R help, the Pokédex diploma.
- Complete PWA (install, icons, offline loading screen).
- Logs, metrics and monitoring.
- Admin tools for the `admin` role.
- Chat moderation: word filter, muting and reporting ([O16](index.md#open-items), Phase 8 D14).
- Production deployment, with automatic PostgreSQL and Redis backups.

## Done When

- The game is public, stable and playable on desktop and mobile.
